# 打开文件历史

显示文件树后，点击顶部“历史”按钮打开独立窗口。默认记录成功打开文件的路径、最近打开时间和次数；重新打开已有标签会激活该标签。置顶记录优先，其余默认按最近打开降序显示，点击路径、时间或次数列可切换排序。在搜索框输入文件名或路径的一部分筛选，支持中文；过滤或排序后会清除选择，避免原行号对应另一文件。

类型框默认 `*` 显示全部类型，可输入 `*.md;*.markdown`、`*.txt` 等，扩展名大小写不敏感。无效类型输入会提示并保留上次有效列表。选择一条记录后点击“置顶/取消”切换置顶；点击“移除记录”只删除该历史元数据，既有文件和已打开的编辑缓冲区都保留。更新在后台执行，期间禁用重复更新操作，完成后刷新磁盘结果。置顶记录优先保留，不随普通容量淘汰丢失，仍受历史格式的硬上限限制。

双击记录或按 Enter 打开文件。失效或不可访问记录保留并标记，点击时提示而不清除记录。文件可访问状态在后台刷新时检查；状态不是实时文件监控。刷新按钮重新读取磁盘历史，包括其他实例写入的记录。后台读写错误显示 Windows 错误码，读失败保留已有列表；写失败的事件目前没有自动重试。

切换标签、关闭标签及正常退出时会异步记录当前光标所在行和列。历史窗口重新打开已关闭的文件时，恢复快照中的光标位置并滚动到光标；列采用编辑器的 Tab 展开规则，支持中文。文件被修改后，超出的行列会限制到实际文件范围。已打开文件直接激活原标签，保留其当前选区和未保存内容。此功能保存的是光标阅读位置，不是单独的顶部滚动位置；窗口列表是快照，必要时点击刷新读取最新位置。暂停历史记录时也暂停位置写入，已删除/清空记录不会被旧标签的位置更新重新创建。

取消“记录打开历史”可暂停记录，不删除既有记录。原有“保存最近文件”关闭时也不记录新历史，历史窗口的记录开关随之禁用。配置遵守原有保存设置开关。设置文件的 `[Settings2]` 支持 `HistoryEnabled=true/false` 和 `HistoryMaximum=500`，条数范围 1–10000；可直接在窗口“条数上限”填写整数并点击“应用上限”。新上限在下次历史写入时生效，不立即删除列表；置顶记录优先保留。

点击“清空历史”后按钮变为“确认清空”，再次点击才会移除全部历史（含置顶记录），不会删除原文件或关闭标签。可点击“取消清空”，确认也会在 15 秒后自动取消。清空作用于完整历史，不只清除当前筛选出的行。

历史快照使用当前 INI 文件路径加 `.history`，并通过 `.history.lock` 协调不同实例。无 INI 路径时不创建快照。快照只含路径与元数据，不保存文档全文。退出最多等待两秒完成待写事件，强制终止或超时仍可能丢失尚未提交的事件。

本版完成历史记录、列表、关键词/类型筛选、基本排序、打开、记录开关、置顶、单条移除、清空、条数上限设置和光标阅读位置恢复。重新定位失效文件还在实现中。程序消息驱动的控件检查已通过，尚未进行人工鼠标及跨显示器外观验收。
