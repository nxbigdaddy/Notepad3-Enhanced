# 日志筛选

## 第二十三轮：处理模块

LogFilter_Run 接收不可变 UTF-8 文本快照、关键词或 PCRE2 正则、大小写开关和反向筛选开关，逐行返回匹配行。行号从零开始，offset/length 定位原始行内容，不含换行；matchOffset/matchLength 定位首个实际匹配。反向筛选的匹配长度为零。支持 CRLF、CR、LF 混合换行，保留末尾换行产生的最后空行，空文档视为一行，与编辑器行模型一致。关键词自动转义元字符，Unicode 不区分大小写使用 PCRE2 UTF/UCP。

复用项目现有 PCRE2 静态库，没有新增外部运行时。输入上限 8 MiB、表达式 4096 字节、单行 1 MiB、最多 100000 个结果。匹配上下文限制 100000 次匹配工作、深度 256、堆 8192 KiB；自动 callout 设全次筛选 2000000 调用预算，并检查取消回调。编译错误、非法文本、超限、取消及分配失败各自返回状态，失败不提供部分成功结果。

结果对象调用前应为空；调用方用 LogFilter_Free 释放结果。返回偏移引用原始快照，需要界面同时保留文档 ID 与版本，原文变化后不能直接用旧偏移定位。

**目前仅处理模块接入构建，编辑器尚无日志筛选面板。** 后台快照、取消按钮、结果列表、文档版本守卫、点击定位和实际界面验收将在后续实现。
