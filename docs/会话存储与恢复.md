# 会话存储与恢复

已接入文件菜单的手动保存 / 恢复会话，以及后台周期备份和启动时异常恢复。正常退出后的自动重开会话、恢复目录初始化失败反馈及全部交互验收仍待完成。

## 已实现

`SessionStore.cpp` 保存文档顺序、活动标签、路径、未保存文本原始字节、编码、换行、修改/只读/加密来源标记、选区序列化、光标、滚动、缩放及折叠行。文件加密口令与密钥不在格式中。读取失败不修改调用方已有快照，C 接口返回的文档指针在快照修改或释放前有效。

格式有版本标识、CRC 校验、严格长度和元数据边界校验。文档上限 64 份，单份文本上限 32 MiB，会话明文负载上限 64 MiB，选择状态上限 1 MiB，超限返回失败并保留已有会话，不截断文本。文档编码值将在接入编辑器时再次使用实际支持列表校验。

磁盘文件由 Windows DPAPI 按当前用户保护。每次保存创建独立临时文件，完整写入、刷新并关闭后才原子替换目标；替换或写入失败不覆盖旧会话。临时文件也只包含加密数据。默认保护依赖当前 Windows 用户的登录凭据，通常需同一用户和机器恢复，不是跨账号的便携导出格式。依据：[Microsoft CryptProtectData 文档](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata)。

## 自动异常恢复

恢复目录为 `%LOCALAPPDATA%\Notepad3\Recovery`。每个进程使用带进程 ID 和创建时间的独立文件及独占文件锁；文件锁仍被持有时，另一个实例不读取或清理该备份。启动后先捕获一次，此后每 30 秒捕获全部文档。界面线程读取 Scintilla 和视图状态，后台工作线程对不可变快照进行 CRC、DPAPI 和原子文件保存；尚有任务运行时不重叠启动。

启动扫描失去所有者的备份，取得独占锁后导入。完整工作区先保存至新实例自己的备份，成功后才删除原备份，坏文件保留。显式打开的原有标签不会被恢复缓冲区覆盖。正常关闭确认通过后先写关闭标记，再等待后台任务并清理本实例的备份；超过等待时间时保留关闭标记，下一次启动不会恢复用户已放弃的内容。关闭取消不执行该清理。

`scripts/test-recovery.ps1` 在有 marker 的独立目录运行真正的编辑器进程，生成两个不同编码的未保存标签，然后只强制终止该脚本创建的 seed 进程。24 项检查通过：另一个活动实例不接管备份、异常终止后文本及编码恢复、新所有者获得完整备份，以及正常清理后不再恢复；脚本独立检查磁盘无明文、原备份转移后清理和坏备份字节保持不变。新增检查实际锁定备份文件，确认后台替换失败时旧快照仍有效、首次失败计入提示、连续同类错误不重复提示，以及成功重试清除错误状态。

证据：`artifacts/recovery-test-c3ff870ab3f14f93a5dd3d47c0fbf0ac`。这些是编辑器内的实际运行检查，不代表真实鼠标、对话框及视觉验收。30 秒调度已接入，测试直接调用同一备份回调，不以等待计时器代替内容与磁盘验证。
