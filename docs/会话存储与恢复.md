# 会话存储与恢复

当前已完成存储模块和 C 调用接口，尚未接入工作区自动保存、启动恢复和异常退出恢复，不能把本阶段当作可用的会话恢复功能。

## 已实现

`SessionStore.cpp` 保存文档顺序、活动标签、路径、未保存文本原始字节、编码、换行、修改/只读/加密来源标记、选区序列化、光标、滚动、缩放及折叠行。文件加密口令与密钥不在格式中。读取失败不修改调用方已有快照，C 接口返回的文档指针在快照修改或释放前有效。

格式有版本标识、CRC 校验、严格长度和元数据边界校验。文档上限 64 份，单份文本上限 32 MiB，会话明文负载上限 64 MiB，选择状态上限 1 MiB，超限返回失败并保留已有会话，不截断文本。文档编码值将在接入编辑器时再次使用实际支持列表校验。

磁盘文件由 Windows DPAPI 按当前用户保护。每次保存创建独立临时文件，完整写入、刷新并关闭后才原子替换目标；替换或写入失败不覆盖旧会话。临时文件也只包含加密数据。默认保护依赖当前 Windows 用户的登录凭据，通常需同一用户和机器恢复，不是跨账号的便携导出格式。依据：[Microsoft CryptProtectData 文档](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata)。

## 验证

`scripts/test-session.cmd` 使用 `/W4 /WX` 构建测试。290 项检查通过，其中包括完整往返、中文路径、二进制未保存文本、未命名文档、光标和折叠、所有截断位置、损坏内容、元数据边界、64 文档边界、真实 DPAPI 磁盘往返、无明文检查、目标文件被锁定时保留旧会话、既有文件替换、损坏磁盘文件保留调用方状态、缺失目录及 C 调用接口边界。多数检查是截断位置检查，不能用数量代替工作区验收。

真实磁盘证据：`C:\Users\Administrator\AppData\Local\Temp\np3-session-test-19344-7501375`。测试文件保留，未递归删除目录。

完整 x64 Release 构建通过，模块已加入编辑器构建。

## 下一阶段

1. 从全部标签读取文本与状态，恢复时先校验并构建候选文档，再提交到工作区；失败保持现有文档。
2. 提供保存/恢复入口，正常启动恢复工作区。显式打开文件时保留用户打开意图；恢复缺失/已变更文件时保留缓冲区并提示冲突，不自动覆盖磁盘。
3. 为各进程生成独立、受保护的周期性恢复文件；正常退出处理保存/不保存/取消后清理恢复标记，异常退出下次可恢复。不能让不同实例互相覆盖。
4. 加密来源文档恢复后重新确认密钥，不能因为会话未保存密钥而把文件按明文保存。
5. 真实编辑器测试覆盖未保存缓冲区、多编码、启动、异常终止、损坏/缺失/冲突及恢复失败的完整流程。
