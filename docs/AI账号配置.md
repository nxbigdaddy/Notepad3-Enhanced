# AI 账号配置（v117）

日常直接使用顶部已保存账号/模型下拉。初次配置点击“模型设置”，选择服务地址预设，填写模型与密钥后保存；新账号自动生成内部 ID。设置可再次收起。模型名仍需填写平台可用标识，旧账号配置与密钥继续保留。下面的配置 ID 说明用于高级管理，不是新账号配置必填步骤。

在 AI 面板填写服务地址、模型、超时、配置 ID 与密钥，然后点击保存。配置 ID 只允许 1–64 个英文字母、数字、连字符和下划线，建议使用稳定的 account-1 等标识；留空使用升级前的旧账号。配置 ID 是身份标识，不是 API 密钥。

同一服务的不同账号使用不同 ID 分别保存密钥。再次使用某个 ID 时填写对应地址、模型及超时，密钥栏可以留空保留已有密钥，点击保存后开始操作。活动配置以已保存设置为准。非空 ID 保存后进入“切换已保存账号”列表，最多 32 个配置。选择已有配置会直接启用，恢复它的地址、模型和超时，并清空尚未保存的密钥输入；切换前请先保存想保留的字段。相同 ID 再次保存更新原配置，配置 ID 区分大小写。选中已保存账号后点击“移出列表”可腾出名额；当前活动设置和密钥保留，再次点击保存可恢复到列表。若要删除密钥，使用独立的删除密钥按钮。当前没有自定义显示名功能。

删除密钥仅删除输入 ID 与服务地址对应的密钥；空 ID 删除旧服务密钥。改变地址会使用另一个凭据身份，原地址的密钥仍保留。普通 INI 只包含非秘密设置；API 密钥保存在 Windows Credential Manager。

服务仍须兼容 Chat Completions 协议，远程地址要求 HTTPS，本地回环允许 HTTP。Kimi、DeepSeek、Qwen 或第三方平台的账号、地域、地址和模型需相互匹配；当前仅完成本地模拟验证，尚未完成供应商实测或模型列表功能。

## 服务地址预设

选择 Kimi 中国大陆、DeepSeek 或 Qwen/百炼北京会填入完整 Chat Completions 地址，并清空旧模型、账号 ID 和未保存密钥。选择第三方兼容接口后手动填写完整地址。预设不会启用或请求；填写可用模型、匹配账号/地域的密钥后点击保存。模型名由用户填写，避免使用过时名称。

预设依据：[Kimi 官方接口](https://platform.kimi.com/docs/api/chat)、[DeepSeek 官方示例](https://api-docs.deepseek.com/api_samples/chat_curl/)、[百炼官方兼容接口](https://help.aliyun.com/zh/model-studio/compatibility-of-openai-with-dashscope)。百炼北京通用域名仍受支持，官方推荐业务空间专属域名，可在地址栏手动替换。真实供应商验证仍待提供对应凭据后完成；国内其他区域或国际站需填写自己的地址，预设不保证任意模型或协议可用。

## 请求失败提示

结果栏下方会显示认证、权限、付款或额度、限流或配额、地址或模型、请求参数、服务端、网络/TLS、超时及响应截断等诊断，同时保留数值错误码。分类根据 HTTP 与本地错误状态，不能代替供应商后台的具体原因判断。错误或截断结果不能应用到正文；服务错误正文不展示，避免反射敏感内容。可使用独立“测试（计费）”按钮，真实服务验证仍待完成。

## 独立连接测试

先保存服务地址、模型、超时、配置 ID 和密钥，再点击“测试（计费）”。该按钮仅发送固定短消息 Reply with OK.，不会发送正文、选区或指令栏问题，也不会修改正文。它使用已保存配置，不使用尚未保存的输入。成功表示当前服务/账号/模型完成这一次生成；失败显示认证、权限、网络、限流或响应错误提示。

测试是生成请求，平台可能收取费用，实际输出长度与费用由平台决定；不是仅检查网络是否连通。回复只读，不能应用到正文。本地模拟测试已通过，真实供应商测试尚未进行。
