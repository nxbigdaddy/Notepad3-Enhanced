# 工作区文件树

视图菜单新增 File Tree，26 个语言菜单及文件夹选择、刷新、加载、限额和错误资源接入。面板显示在编辑器左侧，首次使用时根目录来自当前文件所在目录，未命名文件使用工作目录；此后优先恢复已保存的自选目录。可用 Choose Folder 切换目录，Refresh 重建当前树。

目录读取在后台线程执行，结果回到 UI 线程插入原生 TreeView。展开目录时才读取子目录，每页按目录优先及 Windows ordinal 大小写无关顺序排序；不自动展开目录重解析点，避免递归循环。根目录更换或窗口关闭时递增 generation，旧结果丢弃；结果消息携带窗口 cookie，避免被重新创建的面板误用。节点在 TreeView 删除通知时释放，枚举句柄使用 RAII。

双击文件或 Enter 走编辑器 FileLoad 多标签流程，不覆盖当前未保存标签。无效根目录不删除当前树。面板宽度随 DPI 调整，可拖动右侧分隔条改变宽度。普通窗口至少 120 DPI 像素、最多半宽，并保留至少 240 DPI 像素编辑区；极窄窗口退回三分之一。文件和目录有不同图标，控件使用共享主题。跨 DPI 刷新和完整视觉验收仍在推进。

每页最多插入 5000 项，目录未读完时显示 Load next 5000 entries；选中后 Enter 或双击继续读取。Windows 枚举句柄及下一项位置由节点共享状态保留，追加下一页不重建既有节点，保留已展开目录及选择。枚举完成、刷新或关闭时释放句柄。页面内排序，不保证跨页全局顺序；目录正在变化时遵循 Windows 文件枚举语义，需要 Refresh 重读。后台读取使用队列调度，单个面板最多 4 个在途读取；连续展开不会丢掉等待目录。根目录替换清空等待队列并使旧读取失效，旧读取在退出前仍占据并发槽位，完成后唤醒新队列。关闭面板使读取协作取消并释放等待任务，后台持有状态引用直到句柄关闭；不会等待磁盘枚举而阻塞编辑器。Windows 文件枚举自身阻塞期间不能强制终止，目录遍历间检查取消。错误路径提供刷新提示，分页已接入，图标和共享主题已接入，跨 DPI 和实际交互验收仍待完成。文件树根目录以独立设置保存，不纳入文档会话格式。
