# 工作区文件树

视图菜单新增 File Tree，26 个语言菜单及文件夹选择、刷新、加载、限额和错误资源接入。面板显示在编辑器左侧，默认根目录来自当前文件所在目录，未命名文件使用工作目录。可用 Choose Folder 切换目录，Refresh 重建当前树。

目录读取在后台线程执行，结果回到 UI 线程插入原生 TreeView。展开目录时才读取子目录，按目录优先及 Windows ordinal 大小写无关顺序排序；不自动展开目录重解析点，避免递归循环。根目录更换或窗口关闭时递增 generation，旧结果丢弃；结果消息携带窗口 cookie，避免被重新创建的面板误用。节点在 TreeView 删除通知时释放，枚举句柄使用 RAII。

双击文件或 Enter 走编辑器 FileLoad 多标签流程，不覆盖当前未保存标签。无效根目录不删除当前树。面板宽度随 DPI 调整，最多占窗口三分之一，目前尚无拖动宽度、图标及完整主题适配。

首版每目录显示最多 5000 项，超限明确显示提示，尚未分页。这是暂时边界，不代表大目录功能已经全部完成。当前每次展开启动一个后台线程，任务池、并发限流、关闭中断边界和后续分页仍待实现；错误路径提供刷新提示。文件树根目录目前不纳入会话格式。
