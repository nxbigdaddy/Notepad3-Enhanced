# Notepad3 扩展补丁（x64）

## 便捷更新包

下载 Notepad3-更新包-x64.zip，解压后双击 Notepad3-更新.exe，允许管理员授权，选择原目录，点击“安装更新”或“恢复原版”。EXE 内嵌完整补丁，无需手动寻找脚本。操作中请等待完成。使用系统 .NET Framework 与 Windows PowerShell，已在本机 Windows 10 环境编译并验证实际解包内容；未宣称 GUI/UAC 点击已验收。

这是本项目基于 Notepad3 源码构建的扩展升级包，并非官方发布。补丁替换原目录中的 Notepad3.exe，补齐匹配的语言文件、WebView2 加载器、离线渲染资源和许可证。升级后继续使用原快捷方式，不需要重新设置文件关联。

## 安装

1. 保存文件并退出原 Notepad3。
2. 解压整个 ZIP，不能直接在压缩包内运行。
3. 双击 Install.cmd，在目录选择框中选择含 Notepad3.exe 的原安装目录。常见安装目录会预填，可自行更改。
4. 原程序位于 Program Files 等受保护目录时，右键 Install.cmd，选择“以管理员身份运行”。
5. 提示 Patch applied 后，从原快捷方式启动 Notepad3。M 按钮用于打开 Markdown 预览。

只支持 Windows x64 与 x64 Notepad3；32 位或 ARM 程序会被拒绝。不同旧版本的全部配置兼容性尚未逐版验证。INI 配置、用户文档、会话和其他旧工具不在补丁覆盖范围内。Microsoft Edge WebView2 Runtime 仍需已安装；补丁包含加载器，不包含运行时。AI 服务由用户自行配置。

## 恢复原版

保存文件并退出 Notepad3，运行 Restore.cmd，选择同一安装目录；权限要求与安装相同。默认恢复最近一次仍处于 applied 状态的备份。原配置保持，补丁新增的文件删除，原有文件恢复；空的新增目录和备份保留。

备份存放于原安装目录的 .np3-extension-backups 中，请不要删除。若补丁文件后来被其他升级程序或用户修改，恢复会拒绝覆盖，避免丢失后来的改动。可用 PowerShell 显式指定备份目录：

```powershell
.\Apply-Patch.ps1 -TargetDirectory 'D:\Tools\Notepad3' -Restore -BackupDirectory 'D:\Tools\Notepad3\.np3-extension-backups\备份名'
```

安装前核对全部载荷 SHA256，备份原文件后部署，部署出错会尝试自动恢复。SHA256 用于检测包内文件损坏，不是官方签名或发布者身份认证。目录链接/联接点不支持；运行中的目标程序不会被强行关闭。推荐先在原安装目录副本上试用，再升级日常使用的版本。
