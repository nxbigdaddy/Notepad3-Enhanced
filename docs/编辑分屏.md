# 编辑分屏

View 菜单的 Split Editor 打开/关闭左右双视图，26 个语言菜单已接入。两个原生 Scintilla 视图引用当前标签的同一文档：文本、撤销、保存状态和文档版本共用，选区独立。焦点进入视图时切换 Globals.hwndEdit 与直接调用句柄，让编辑菜单、查找和快捷键使用当前视图。只处理活动视图的通知，避免共享文档导致重复版本更新；旧通知处理器同时接受两个控件 ID。

开文件、切换和关闭标签通过工作区刷新将另一视图绑定到同一当前文档，保留工作区文档引用与撤销。关闭右视图恢复主视图为活动编辑器，销毁视图自动释放其文档引用。工作区销毁前关闭分屏。

初始各半宽，6 DPI 像素分隔条可拖动；宽度足够时两视图至少各 120 DPI 像素，窄窗口退回均分，零宽空间安全处理。捕获鼠标、松开结束、CancelMode 恢复开始比例，捕获转移停止拖动。切换文档时复制字体/文字色/背景色/字号及粗斜体；只读、内部编码、换行及缩进状态同步。每标签分别捕获两个视图的多选区序列、anchor/caret、首个可见行、水平滚动、缩放和折行；恢复标签与重开右视图还原相应状态。完整主题/边距/标记样式、会话跨进程保存双视图状态、真实鼠标焦点和保存对话框验收仍待完成，不能视为整个分屏验收完成。

## 第二十二轮：独立折叠
