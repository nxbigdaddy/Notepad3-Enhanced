## 多标签的文档隔离边界

源码审计：`FileLoad()` 在读取前对当前文件调用 `FileSave(FSF_Ask)`，并重置加密、书签导航和撤销；加载后更新 `Paths.CurrentFile`、`Globals.fvCurFile`、当前编码、语法高亮、只读状态、文件监控和自动保存。这些流程目前都作用于同一编辑器。

多标签实现需要同时隔离下列状态，不能仅添加标签控件：

- Scintilla 文档句柄、引用计数及文档内的内容/撤销/修改状态。
- 文件路径、当前编码、换行、FILEVARS、加密上下文、保存时间保留及设置文件锁定状态。
- 视图的选区、光标、首行、横向滚动、折叠、Lexer、只读及缩进设置。
- 文件监控的异步观察任务与 generation：切换前终止旧观察，恢复路径后启动新观察，不能复制线程或事件句柄。
- 自动保存与退出确认：所有修改标签逐一处理，取消时保留工作区；不能只检查活动标签。
- 后续 AI 回调和预览：绑定稳定文档 ID 和版本，关闭后丢弃，不能仅依靠文件名。

## 验证标准

解析器测试、完整构建、运行时状态和 UI 交互分别记录。实际 UI 读取工具现有窗口身份绑定错误不能替代功能验收，也不能因此把未验收条目标成通过。测试开发包与源构建输出隔离，保护用户正在编辑的窗口。
