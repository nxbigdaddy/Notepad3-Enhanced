# 批量文本工具

入口为“查看 → 面板 → 批量文本工具”。点击“选择文件…”多选待处理文件，或先使用普通打开命令打开文件，再选择操作并点击“预览已打开文档”。未命名文档也可参与，列表用文档编号区分。文件选择入口会加入多标签工作区；预览覆盖已打开文档，应用时勾选需要处理的结果。

支持区分大小写的字面文本替换、逐行排序、保留首次出现顺序的去重、行尾空格/制表符清理、删除空行、JSON 格式化和压缩。排序使用 UTF-8 字节顺序；空格行不算空行。行工具按每份文档的换行设置生成结果，保留是否有末尾换行。替换不使用正则表达式，不递归替换新生成文本。

转换在后台使用不可变快照。列表显示文档路径和状态，点击一行查看原文与结果；实际变化的文档默认勾选，只读、未改变和错误项默认不勾选。只有点击“应用勾选结果”才修改文档。更改操作或替换参数后必须重新预览；取消和关闭面板使后台任务取消，不应用结果。

应用前核对整个选择中的文档 ID、版本、原文字节和只读状态。任一文档已变化、已关闭或被设为只读，整批拒绝。每份文档的替换组成一个撤销动作；可以逐份撤销。中途失败时尝试反向撤销本批修改，并检查原文是否恢复；预览仍保留原文。极端内存不足导致回滚也失败时返回失败，不报告成功。

应用保留文件路径与编码，文档成为未保存状态，需要使用正常保存命令写入文件。预览与应用均不直接覆盖磁盘文件。最大 64 份文档，单份输入 8 MiB，整批输入/输出各 32 MiB，每份最多 100000 行。原文含 NUL 或非法 UTF-8 时不生成可应用结果。

文件加入前检查路径存在、不是目录、去重和标签容量。已打开路径复用原标签，保留未保存文本；加入后恢复原活动标签，初始空标签允许正常复用。缺失路径在打开任何文件前拒绝；真正打开过程中若文件变化或 I/O 失败，已加入的标签仍保留并报告失败，不覆盖已有缓冲区。成功加入文件后旧确认失效，必须重新预览。文件对话框取消不加入文件。
