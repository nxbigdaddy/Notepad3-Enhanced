# 主题与扩展面板

程序可选择深色、浅色或跟随系统。原有深色主题菜单命令保留样式重置提示。Settings/WinThemeDarkMode 为 0（自动）、1（深色）或 2（浅色）。浅色 Windows 系统也可使用程序明确深色；系统 API 不支持时保留浅色基础界面，高对比度仍优先使用系统颜色。

AI、日志、批量文本和文件树使用统一的面板颜色与 DPI 消息字体；主题切换和系统颜色通知刷新这些控件，保留编辑文本、版本、保存状态与批量预览。文件树刷新图标资源时保留节点和展开状态。M 按钮用于 Markdown 预览。

scripts/test-workspace.ps1 -ThemeMode dark -Preview 和 -ThemeMode light -Preview 使用隔离 INI 与隐藏独立进程，不改系统设置。第五十轮深色/浅色启动各 206 项检查通过，AI/Markdown 综合 239 项通过。证据见迭代进展。当前为 Windows 10/96 DPI 控件结构、颜色、字体和 GDI 的原生读回；完整屏幕视觉、高对比度与跨 DPI 验收尚未完成。
