# 提示词管理（v117）

AI 面板中的提示词编辑框支持多行输入和滚动。输入名称与内容，点击“保存提示词”。同名保存覆盖已有内容，改名保存创建另一条，最多 32 条。内容最多 4096 UTF-8 字节，中文通常占多个字节。

从“选择已保存提示词”下拉载入一条，可以编辑并再次保存，也可以直接选择解释、翻译、改写、生成或其他操作执行。载入和保存不会自动发出 AI 请求。普通操作仍通过差异预览和手动确认修改正文。

删除时先载入想删除的记录，再点击“删除提示词”。若编辑框内容已改变，删除会拒绝；重新载入原记录后可以删除。删除后输入框草稿保留。改名另存不会删除原名称。

提示词存于 Notepad3 普通设置 INI 的 AIPrompt 区段；采用 UTF-8 十六进制编码保留多行和 Unicode，编码不是加密。账号 API 密钥仍由独立 Credential Manager 保存。当前未提供提示词导入导出、变量替换或分类标签；这些不影响基础保存、编辑、删除与快速使用。

## Markdown 操作（v123）

操作下拉新增 Markdown 大纲、标题建议、Markdown 表格、待办提取、Mermaid 图。选区非空时处理选区，否则处理当前文档；提示词编辑框仍可补充约束。点击执行后只显示提案，人工检查结果，点击应用才替换对应范围；一次撤销可恢复。标题建议输出五个候选标题，不自动重命名文件。

这些操作通过不同 system 指令要求保留事实/不确定性，不编造负责人、期限、关系；Mermaid要求单一代码块并避免链接/click/HTML。提示词不能保证模型输出可靠或图可渲染，需人工核对；尚未进行真实供应商内容质量验收。现有版本/原文/只读/过期结果保护继续生效。
