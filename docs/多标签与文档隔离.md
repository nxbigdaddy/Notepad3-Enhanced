# 多标签与文档隔离

开发包：`artifacts/workspace-tabs-x64-v7/Notepad3.exe`。

## 使用

- 打开文件时新增标签，保留其他文件的未保存内容；重复打开当前工作区已有文件会切回该标签。
- 新建文件创建空白标签。启动时唯一未修改的空标签可直接用于第一次打开。
- 点击标签或使用 Ctrl+Tab / Ctrl+Shift+Tab 切换。
- 点击标签栏右侧 ×、文件菜单“关闭标签”或 Ctrl+F4 关闭当前标签；最后一份关闭后保留空白文档。
- 修改标签显示 `*`。关闭修改文档使用现有保存/不保存/取消对话框；关闭窗口逐份处理文档，取消后回到原活动标签。
- 拖放多个文件默认打开为标签，按住 Ctrl 保留原有新窗口方式。
- 当前上限为 64 份文档；超限和分配失败时保留已有标签。

## 状态隔离

工作区持有每份 Scintilla 文档的引用，内容、修改状态与撤销记录保留在各文档中。另存路径、编码、换行、FILEVARS、只读状态、缩进、换行显示模式、缩放、序列化选区、滚动和标题附加信息在切换边界保存和恢复。

每份文档有稳定 ID 和文本版本。Markdown 预览用文档 ID 区分未命名文件。文件监控在切换前终止，再按新文档路径重建；异步通知带文档 ID，旧标签的通知不会作用于新标签。保留加载时的磁盘观察基线，非活动文件被外部修改后，切回仍能标记变化，保留编辑缓冲区并沿用已有冲突处理。

加密上下文按文档存放，关闭时清零释放；不会把口令或密钥写入日志或会话文件。关闭和系统结束会话会逐份处理文档；关闭前的设置保存与文档资源释放分别处理。拖放临时文件快照只要仍被任意标签持有就不会被清理。

本轮为逐步迁移：工作区代码在 `src/Workspace/DocumentWorkspace.inc`，通过同一切换边界接入单文档遗留状态。后续将文件保存等逻辑逐步收敛到独立模块。
