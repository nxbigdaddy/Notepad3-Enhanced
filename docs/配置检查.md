# JSON / INI 配置结构检查

编辑菜单的高级命令中新增 Check JSON Structure 与 Check INI Structure，26 个语言菜单和提示资源已接入。检查当前整个缓冲区，不以选区代替完整配置；只读文档也能检查。首次错误按编辑器字节坐标选中对应字符并滚动到位置，提示原因和行/列，不替换文本或增加撤销项。

JSON 复用已有词法保留解析器，先检查 UTF-8 与空字节，接受开头 UTF-8 BOM，限制 8 MiB 和 128 层嵌套。诊断偏移包含 BOM；Scintilla 行/列用于显示定位。编辑器正常文件加载的内部代码页固定 UTF-8，因此不同磁盘编码加载后使用同一检查路径。

INI 接受空文件、全行 ; / # 注释、全局键、[section] 节头、键=value、空值及节头后的注释；空白节名、嵌套方括号、节头后的非注释文本、空键或缺少等号会报告结构错误。重复节/键允许，不根据重复内容猜测应用读取规则。值里的等号、分号和 # 保留为值，不用于拆分或推断类型。当前检查单行键值结构，不检查应用 schema、数字范围、路径存在性、必需键或不同 INI 方言的多行值。

输入上限 8 MiB，拒绝非法 UTF-8、空字节和 INI 不支持的控制字符。错误报告只给首次问题，修复后可再运行；有效结果仅说明结构无错误，不能证明应用配置正确。
