# JSON 文本工具

入口：**编辑 → 高级 → JSON 格式化 / JSON 压缩**。

有普通选区时只处理选区；没有选区时处理全文。多选区、矩形选区和只读文档禁止修改。格式化采用两空格缩进和文档当前换行方式；压缩删除字符串以外的空白。

只调整空白，不重新解析并序列化数值：长整数、小数、指数、重复字段、字段顺序、字符串转义和字符串原始字节均保留。输入 UTF-8 BOM 保留。支持标准 JSON 的对象、数组、字符串、数值、布尔值、null 和根标量，不支持 JSON5 注释、尾逗号及未加引号的字段名。

语法错误显示相对处理范围的字节位置，不替换原文。输入上限 8 MiB，嵌套上限 128 层，输出上限 32 MiB；超限或分配失败同样不替换。这里校验 JSON 结构和转义，不检查文档编码或 Unicode 代理对。已有编辑器的编码选择负责文件编码。

修改用编辑器已有撤销事务包裹；未产生差异时不创建撤销项。不会自动保存文件。

## 真机验收步骤

1. 在开发包中打开 `tests/fixtures/json-tools.json`，执行 JSON 格式化，检查中文、字段顺序、重复字段和长数字保持原样。
2. 按 Ctrl+Z，应恢复原文；Ctrl+Y 应恢复格式化结果。
3. 在一段非 JSON 文本中选中一个完整 JSON，执行压缩，检查选区以外的字节不变。
4. 在 JSON 中添加尾逗号，执行格式化，应提示错误，文档内容和撤销历史不变。
5. 切换只读或矩形选区，确认菜单禁用。
