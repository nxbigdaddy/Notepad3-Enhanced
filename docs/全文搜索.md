# 文件与正文搜索

在“查看”菜单打开文件树，点击顶部“搜索”。目录每行填写一个；默认仅搜索 Markdown，可修改为 *.md;*.txt 等格式，也可填 *。路径关键词用于筛选文件名/路径，排除目录以分号分隔，只填目录名称。可取消“包含子目录”。

正文关键词留空时列出文件。填写后点击“搜索”，结果显示匹配行、列和上下文；可选择区分大小写和整词。双击或 Enter 打开匹配标签并选中文字；同一文件已打开时复用原标签。正文读取磁盘上的已保存内容；如果当前编辑内容与结果上下文不同，会提示重新搜索，不覆盖未保存修改。点击“停止”取消扫描。

默认使用字面关键词，勾选“正则”使用 PCRE2；例如 ^标题、fixt(?:ure) 或 \p{Han}+。正则按单行匹配，不跨行；零长度匹配跳过。单个匹配不超过 4096 字符，回溯步数/深度受限，超限记为文件错误。支持严格 UTF-8 和带 BOM 的 UTF-16 LE/BE；默认跳过超过 8 MiB、二进制、损坏字符或链接文件。最多枚举 100000 文件/发布 100000 匹配，达到上限会提示。状态栏显示错误和跳过数量；点击“错误详情”查看失败路径、Windows 错误码及系统说明，点击“返回结果”回到原列表。文件类型右侧 ▼ 提供四种预设；搜索启动后记住类型、排除目录和四个开关，程序重启按原有配置保存规则恢复。关闭自动保存时不写入磁盘。正文查询和额外搜索根目录不持久化；再次打开时不自动扫描。
错误详情是只读报告，保存本次明确搜索范围内的路径和错误，不记录全文；最多展开 100 项且限制显示文字总量，长路径截断后加省略标记。错误不会丢弃其他目录的有效结果；新搜索会替换旧报告。达到显示上限会提示未展开数量。
