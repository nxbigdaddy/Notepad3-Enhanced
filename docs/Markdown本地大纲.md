# Markdown 本地大纲

在文件树顶部点击“大纲”，打开当前编辑缓冲区的本地标题列表。支持未保存文档，无需AI或网络。双击标题或选中后点击“定位”跳转到原始字节位置；“刷新”重新读取当前活动文档。

编辑或切换文档后，旧大纲禁止定位并要求刷新。关窗释放快照，重新打开重新读取；不写文档、配置或历史文件。当前支持最多1MiB缓冲区、4096标题；超限或编码问题显示错误。解析器支持ATX/单行Setext、围栏排除及BOM/注释等基础规则，嵌套引用/列表、复杂HTML块、多行Setext尚未完整支持。标题保留原始行内Markdown。

第一版按需同步刷新，不自动扫描其他标签；大文件异步、大纲主题/DPI、键盘导航和自动刷新仍待继续。窗口使用系统原生颜色，尚未完成人工鼠标/高DPI外观验收。

## 列表键盘与布局（v131）

大纲列表获得焦点时，Enter定位选中标题、F5刷新、Esc关闭；打开窗口和刷新后选中第一项。刷新批量关闭列表重绘，避免逐条闪烁；列表分配失败会清空快照，不保留可能错位的部分标题。

窗口行高/最小尺寸按当前DPI计算，并处理系统提供的WM_DPICHANGED位置尺寸建议；字体和主题仍为系统默认，实际跨屏/高DPI外观尚未人工验收，不能视为完整DPI适配。
